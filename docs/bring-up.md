# 接线与首次调试

## 1. 电气连接

按根目录 README 的引脚表连接模块。蓝牙模块 TX 接主控 PA3，RX 接主控 PA2；调试串口 TX 为 PA9。I²C2 总线使用 3.3 V 上拉，MPU6050 地址为 0x68，OLED 地址为 0x3C。

TIM2 使用 PA15/PB3，TIM3 使用 PB4/PB5，保留 SWD 下载接口。PB8/PB9 分别对应驱动代码中的左/右 PWM，AIN1/AIN2 为 PB14/PB15，BIN1/BIN2 为 PB13/PB12。结合图纸与实际模块核对电机通道对应关系，TB6612 的 STBY 保持有效电平。

固件采用外部 8 MHz 晶振，经 PLL 倍频到 72 MHz。若实际板卡晶振不同，应同步修改时钟树和外设时序。

## 2. 构建与烧录

运行结构检查及固件构建，将 HEX 烧入 STM32，或将 BIN 烧至 0x08000000。上电后电机保持停止，OLED 显示俯仰角、左右轮编码器脉冲之和与使能状态。

## 3. 确认传感器与反馈方向

1. 固定车体、架空车轮，检查供电、驱动通道与传感器安装方向。
2. 前后缓慢倾斜车体，确认俯仰角变化方向与 Y 轴角速度定义一致。
3. 手动转动两轮，观察编码器增量；前进方向的左右反馈应一致。控制任务中左轮增量取反，右轮保持原符号。
4. 在 `pt_pid.c` 调整 `Car_zero`，使其对应机械平衡点。

## 4. 使能与参数整定

串口终端使用蓝牙通道 9600 baud、8N1，发送 `$ARM#`。当有效姿态距机械零点小于 8° 时，控制任务执行使能，OLED 显示 ARMED。`OK:QUEUED` 仅表示命令入队。

架空车轮确认：向前倾斜时，轮子应向前追随；方向相反时，应先调整驱动极性或传感器轴向。随后在支撑条件下整定直立环比例与角速度反馈，再调整速度 PI，记录不同参数下的角度波动、编码器反馈和输出饱和情况。

发送 `$STOP#` 可请求停止；倾角偏离超过 35°、姿态数据超时或控制周期超时也会停止电机。停止后速度积分清零，再次运行需要重新使能。

## 5. 调试观察

- OLED：俯仰角、编码器增量、ARMED / STOPPED。
- USART1：115200 baud，输出收到的蓝牙完整帧。
- 调试器：观察 `gGlobalData.PitchAngle`、`gGlobalData.data.gyro_y`、PID 参数与任务栈。
- 链接 MAP：确认 Flash / RAM 布局；GNU 链接器按 64 KB / 20 KB 限制检查空间。

## 6. 配套文件

`hardware/平衡车.sdr` 为原始 SmartDraw 图纸，保留其文件格式。固件引脚映射以 README、`main.h`、`tim.c` 与 `usart.c` 为准。
